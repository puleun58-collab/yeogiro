제1조 목적

이 약관은 [[운영자 실명 또는 법인명]](이하 “운영자”)이 제공하는 여행 일정 관리 PWA “여기로”(이하 “서비스”)의 이용 조건과 계정·여행·공유 데이터 관리 기준을 정합니다.

제2조 서비스 내용

  1. 여행명, 기간, 도시, 일정, 항공편, 숙소, 예약정보, 경비, 준비 체크리스트 관리
  2. Google 로그인, 계정별 여행 목록과 새 기기 복원
  3. 초대 링크와 역할별 공동 편집
  4. 기기별 오프라인 저장과 동기화
  5. 예약 PDF·이미지의 기기 저장 및 선택적 AI 분석
  6. 대표사진, 날씨, 지도, 경로, 환율, 캘린더·JSON 내보내기
  7. 변경 이력, 휴지통, 기기 관리, 긴급 복구

현재 서비스는 무료이며 결제 기능이 없습니다. 향후 유료 기능을 도입하면 가격, 결제 조건과 환불 기준을 적용 전에 별도 고지합니다.

제3조 약관 동의와 계정

  1. 로그인 버튼 가까이의 약관·개인정보 처리방침 링크를 확인하고 “Google로 계속하기”를 선택하면 표시된 버전에 동의한 것으로 봅니다.
  2. Google의 계정 고유 식별자, 표시명, 이메일, 프로필 사진 URL과 이메일 확인 여부로 자체 계정을 만듭니다. Google 비밀번호는 받거나 저장하지 않습니다.
  3. 로그인하지 않아도 기존 기기의 여행을 오프라인으로 열 수 있습니다. 새 기기 복원과 계정 세션 관리에는 로그인이 필요합니다.
  4. 이용자는 Google 계정, 기기, 초대 링크와 긴급 복구 코드를 안전하게 관리해야 합니다.
  5. 운영자는 공격·권한 우회가 의심되면 요청 제한, 세션 해지 또는 접근 제한을 할 수 있습니다.

제4조 기존 여행의 계정 연결

  1. 계정 도입 전에 만든 여행과 기존 기기 접근은 계속 유효합니다.
  2. 로그인만으로 기존 여행을 강제로 귀속하지 않습니다. “여행 연결”을 선택하면 서버가 유효한 기존 접근정보를 확인한 후 membership을 연결합니다.
  3. 다른 계정에 연결되었거나 membership이 중복되는 경우 연결을 거부합니다.
  4. 연결 후 같은 Google 계정으로 로그인한 새 기기에 여행을 자동으로 내려받습니다.
  5. 이전 연결 코드와 긴급 복구는 호환을 위해 유지하되 일반 기기 교체에는 Google 로그인을 우선합니다.

제5조 여행 소유권과 공유 권한

  1. 새 여행을 서버에 처음 저장한 이용자는 소유자가 됩니다.
  2. 소유자는 초대·권한·소유권·휴지통·긴급 복구·여행 삭제를 관리합니다.
  3. 편집 가능 참여자는 내용을 편집하고 보기 전용 참여자는 열람합니다.
  4. 초대받은 사람은 역할에 따라 일정, 예약번호, 경비, 공용 준비물, 참여자 표시명과 변경 이력을 볼 수 있습니다.
  5. 초대 링크는 재전달될 수 있습니다. 1회용·만료 설정을 사용하고 필요하면 취소하세요.
  6. 파일 원본은 저장한 기기에만 있고 다른 참여자는 메타데이터를 볼 수 있습니다. 압축 대표사진은 참여자에게 공유됩니다.
  7. 이용자는 다른 사람의 개인정보를 입력·공유할 권한을 확인해야 합니다.

제6조 데이터 저장, 동기화와 오프라인 사용

  1. 여행 데이터는 기기의 IndexedDB와 Cloudflare D1 사이에서 동기화됩니다. 오프라인 변경은 기기에 대기합니다.
  2. 충돌 시 서버 최신본 또는 이 기기 변경본을 선택할 수 있습니다.
  3. 인터넷, 저장공간, 브라우저 설정과 외부 서비스 상태에 따라 기능이 제한될 수 있습니다.
  4. 앱·브라우저 데이터 삭제나 기기 분실은 기기에만 있는 파일 원본을 제거할 수 있습니다. 필요한 자료를 별도 백업해야 합니다.
  5. 운영자는 합리적으로 서비스를 유지하지만 중단 없는 동작, 모든 기기 호환과 영구 보존을 보장하지 않습니다.

제7조 예약 문서와 AI 분석

  1. 원본은 기본적으로 기기에 저장됩니다. 분석 실행 시에만 최대 8MB 문서가 Cloudflare Worker와 Workers AI로 전송됩니다.
  2. AI 결과는 후보값이며 바로 저장되지 않습니다. 날짜, 시간, 공항, 예약번호, 숙소와 금액을 원문으로 확인한 후 적용해야 합니다.
  3. AI 결과만 믿고 탑승, 체크인, 결제, 환불 또는 출입국 결정을 해서는 안 됩니다.
  4. 법이 허용하는 범위에서 운영자는 검토하지 않은 AI 결과의 오류로 인한 손해를 책임지지 않습니다. 운영자의 고의·중대한 과실 등 제한할 수 없는 책임은 제외합니다.

제8조 날씨, 지도, 경로와 환율

  1. 외부 공개 API의 날씨, 지도 타일, 지오코딩, 경로와 환율 데이터를 사용합니다.
  2. 예보, 좌표, 경로, 소요시간과 환율은 지연되거나 부정확할 수 있습니다.
  3. 환율은 여행 경비 정리용 참고값이며 금융 거래, 회계, 세무 또는 투자 판단 기준이 아닙니다.
  4. 출발 전 항공사, 숙소, 교통·기상·금융기관의 공식 정보를 확인해야 합니다.
  5. Google Maps 등 외부 페이지에는 해당 제공자의 약관과 개인정보 정책이 적용됩니다.

제9조 JSON 백업과 복원

  1. 백업에는 여행 데이터와 현재 기기에서 읽을 수 있는 일부 파일 원본이 포함될 수 있습니다.
  2. Google 계정 식별자·이메일, 로그인 쿠키·토큰, 기존 접근·초대 토큰, 긴급 복구 코드와 서버 보안 이벤트는 포함하지 않습니다.
  3. 백업에는 예약번호, 위치와 비용이 포함될 수 있으므로 안전하게 보관해야 합니다.
  4. 기존 여행 복원은 현재 membership과 역할을 바꾸지 않으며 보기 전용 이용자는 서버를 덮어쓸 수 없습니다.
  5. 새 여행 복원은 ID를 다시 만들고 서버에 처음 저장한 현재 계정 또는 기기가 소유자가 됩니다.
  6. 앱 밖으로 다운로드하거나 전달한 사본은 운영자가 삭제할 수 없습니다.

제10조 로그아웃, 여행 나가기, 여행 삭제와 계정 삭제

  • 로그아웃: 선택한 계정 세션만 종료하며 기기 오프라인 데이터는 남습니다.
  • 다른 기기 로그아웃: 선택한 기기의 로그인만 종료합니다.
  • 여행 공유에서 나가기: 내 참여 권한과 기존 여행 세션을 해지하며 여행 자체는 유지합니다.
  • 여행 삭제: 소유자만 할 수 있으며 서버의 여행과 종속 데이터를 삭제해 모든 참여자의 접근을 끝냅니다.
  • 계정 삭제: Google 연결, 계정 개인정보, 로그인 세션과 비소유 여행의 내 권한을 삭제합니다. 공유 여행은 유지하고 표시명은 “탈퇴한 사용자”로 익명화합니다. 소유한 여행이 있으면 소유권 이전 또는 여행 삭제를 먼저 해야 합니다.

계정 삭제 성공 후 현재 기기의 여기로 IndexedDB와 yeogiro-* 웹 저장소를 삭제합니다. 다운로드한 JSON, 다른 사람이 보관한 사본, 외부 제공자의 적법한 보존분은 별도입니다.

제11조 이용자의 의무와 금지행위

  1. 타인의 계정·세션·초대·복구 코드를 무단 사용하거나 권한을 우회하는 행위
  2. 개인정보·기밀정보를 권한 없이 입력·공유·분석하는 행위
  3. 악성·불법·권리 침해 콘텐츠를 저장하거나 전송하는 행위
  4. 과도한 자동 요청 또는 요청 제한 우회
  5. 서비스의 보안, 가용성, 데이터 무결성을 해치는 행위
  6. 법령 또는 제3자의 권리를 침해하는 행위

위반이 확인되거나 합리적으로 의심되면 운영자는 관련 세션·초대·접근을 제한할 수 있습니다.

제12조 이용자 콘텐츠와 지식재산권

  1. 이용자가 입력·업로드한 정보와 파일의 권리는 이용자 또는 정당한 권리자에게 있습니다.
  2. 이용자는 서비스 제공, 동기화, 공동 편집, 복원과 선택한 AI 분석에 필요한 범위의 처리를 허용합니다.
  3. 운영자가 권리를 갖는 코드, 브랜드, 디자인과 문서는 관련 법령으로 보호됩니다.
  4. 외부 지도·날씨·환율 데이터에는 각 제공자의 이용조건이 적용됩니다.

제13조 서비스 변경과 중단

  1. 운영자는 보안, 법령, 외부 API와 기술 환경 변화에 따라 기능을 수정·중단할 수 있습니다.
  2. 계정, 데이터 보존과 공유 권한의 중요한 변경은 가능한 범위에서 사전 고지합니다.
  3. 긴급 보안 대응과 외부 장애 등 사전 고지가 어려운 경우 사후에 알릴 수 있습니다.
  4. 서비스 종료 시 [[최소 사전 고지 기간]] 전에 알리고 합리적인 JSON 내보내기 기간을 제공합니다. [[적용 법령상 기간 확인 필요]]

제14조 책임의 범위

  1. 서비스는 여행 정리 도구이며 여행상품 판매, 예약 대행, 운송, 숙박, 보험, 금융 또는 전문 자문 서비스가 아닙니다.
  2. 이용자 입력, 참여자 변경, 외부 API 또는 AI 정보의 정확성을 보장하지 않습니다.
  3. 중요 예약·결제·출입국·안전 정보는 공식 제공처에서 확인하고 필요한 백업을 유지해야 합니다.
  4. 법이 허용하는 범위에서 무료 서비스 장애, 외부 중단, 기기 데이터 삭제, 이용자의 링크·백업 관리 부주의로 인한 책임을 제한할 수 있습니다.
  5. 운영자의 고의·중대한 과실과 법령상 제한할 수 없는 소비자 권리는 제한되지 않습니다.

제15조 개인정보

개인정보 처리에는 별도의 여기로 개인정보 처리방침이 적용됩니다.

제16조 약관 변경

  1. 변경 시 버전, 공고일과 시행일을 공개 페이지에 표시합니다.
  2. 권리를 중대하게 제한하거나 새로운 개인정보 처리를 요구하는 변경은 [[적용 법령에 따른 고지 기간과 방법]]으로 알리고 필요한 경우 다시 동의를 받습니다.
  3. 별도 동의가 필요한 변경에는 단순 계속 사용에 의한 동의를 적용하지 않습니다.
