## 2. 계정과 복원 흐름

1. 사용자가 Google 로그인을 선택하면 PKCE·state·nonce를 사용해 Google OAuth를 수행한다.
2. Worker는 ID token을 검증하고 Google `sub`, 표시명, 이메일, 프로필 사진 URL, 이메일 확인 여부로 계정을 식별한다. Google 비밀번호, access token, ID token은 장기 저장하지 않는다.
3. 로그인 성공 뒤 해당 계정의 membership으로 여행 목록을 불러온다. 새 기기 복원의 기본 경로는 같은 Google 계정 로그인이다.
4. 로그인만으로 기존 기기 여행을 자동 귀속하지 않는다. 사용자가 “여행 연결”을 선택하고 기존 Bearer 세션이 유효할 때만 membership을 추가한다.
5. 계정 도입 전 연결 코드와 이미 발급된 긴급 복구 코드는 레거시 호환 경로로 유지한다. 신규 긴급 복구 코드 발급 API는 `410 Gone`을 반환한다.
6. 기존 복구 코드 교환 시 D1의 해시와 상수 시간 비교하며, 성공하면 복구 해시를 지우고 기존 로그인 세션을 해지한 뒤 새 세션을 만든다.

## 3. JSON 데이터 내보내기·가져오기 경계

JSON 기능은 설정의 “고급 데이터 관리”에만 노출하며 사용자가 버튼을 누른 경우에만 실행한다. 자동 생성·자동 다운로드·계정 복원은 하지 않는다.

### 포함 가능

- 여행 기본정보, 일정, 항공편, 숙소, 경비, 공용 준비 체크리스트
- 참여자·분담 표시를 위해 여행 상태에 들어 있는 일반 참조 정보
- 현재 기기에 실제 원본이 있는 예약 파일과 대표사진 data URL
- 파일 누락·불일치 요약

### 항상 제외

- Google `sub`, 이메일, 프로필 사진 URL과 기타 계정 식별정보
- 계정 세션 쿠키·토큰·해시
- 기존 여행 접근 토큰, 초대 토큰, 복구 코드 원문·해시
- OAuth state, nonce, PKCE verifier
- Client Secret, API key와 서버 보안 이벤트·IP 해시
- 브라우저 권한, 설치 안내 상태와 오류 진단 기록

기존 여행으로 가져올 때 현재 membership과 역할은 바꾸지 않는다. 보기 전용 사용자는 서버 상태를 덮어쓸 수 없다. 새 여행으로 가져오면 여행과 하위 ID를 다시 만들고, 서버 최초 저장 시 현재 로그인 계정 또는 현재 기기가 소유자가 된다.

## 5. 로그아웃·공유·삭제 상태 전이

- 로그아웃: 현재 계정 세션만 해지한다. 오프라인 여행 캐시와 원본 파일은 기기에 남는다.
- 기기별 로그아웃: 선택한 `auth_sessions`만 해지한다.
- 여행 나가기: 해당 참여자의 membership과 기존 여행 세션을 해지하며 공유 여행은 유지한다.
- 여행 삭제: 소유자만 가능하며 D1의 여행과 종속 데이터를 물리 삭제한다.
- 계정 삭제: 소유 여행이 있으면 차단한다. 비소유 공유 여행은 유지하고 표시명을 익명화한 뒤 membership·세션·Google 연결·계정 개인정보를 삭제한다.
- 계정 삭제 화면은 선택적 데이터 내보내기를 안내한다. 성공 후 클라이언트는 여기로 IndexedDB와 `yeogiro-*` 웹 저장소를 삭제한다.
- 사용자가 내려받은 JSON 파일, 다른 사람이 보관한 사본과 외부 제공자 의무 보존분은 앱의 계정 삭제로 제거할 수 없다.

## 7. 운영상 미확정 법적 항목

저장소와 운영자가 제공한 정보로 확정하지 못한 사항은 다음과 같다. 사실이 확인되기 전까지 임의의 값은 공개 문서에 넣지 않는다.

1. Cloudflare 각 제품의 요청별 실제 처리 국가와 운영 계정·계약별 로그 보존 세부조건
2. OSMF·OSRM 계열 개별 운영자의 요청 로그 보존기간과 실제 처리 국가
3. 배포 전 또는 정기적인 대한민국 개인정보·약관 전문 법률 검토 여부
4. 과거 버전에서 논리 삭제된 레거시 여행 행이 운영 D1에 남아 있는지에 대한 운영 데이터 점검 결과

현재 서비스에는 사업자등록번호, 통신판매업 신고번호, 유료 결제, 광고·마케팅 수신 기능이 없으므로 관련 정보를 만들거나 고지하지 않는다.

## 8. 회귀 검증 기준

- 정책 버전 `1.1`이 Worker, 로그인 동의 기록, 공개 정책 페이지와 Markdown 원본에서 일치한다.
- Google OAuth state·nonce·PKCE·1회 소비와 세션 회전이 유지된다.
- 신규 복구 코드 발급은 `410`이고 기존 복구 코드 교환은 유지된다.
- 같은 Google 계정 로그인으로 새 기기 여행 목록이 복원된다.
- 기존 여행 연결은 유효한 기존 세션을 요구하고 다른 계정 소유권을 침해하지 않는다.
- JSON은 사용자 동작으로만 생성되며 인증·OAuth·복구 비밀값을 포함하지 않는다.
- JSON은 현재 기기에 있는 파일 원본을 포함할 수 있고 누락 원본을 보고한다.
- 계정 삭제 전에 선택적 내보내기 경로가 있고, 소유 여행이 있으면 삭제가 차단된다.
- 일반 내 정보·데이터 보관 상태 화면은 복구 코드와 JSON 백업 상태를 주요 계정 안전 수단으로 표시하지 않는다.
