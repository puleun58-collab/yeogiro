# 여기로 개인정보 처리방침

> 정책 버전 1.0 · 공고일 2026-09-07 · 시행일 2026-09-07 · 최종 수정일 2026-09-07
>
> 이 문서는 현재 코드와 데이터 흐름을 반영한 운영 초안이며 법률 자문이 아닙니다. `[[...]]`로 표시된 운영자·국외 이전 정보는 공개 운영 전에 확인·보완해야 합니다.

여기로 운영자 `[[운영자 실명 또는 법인명]]`(이하 “운영자”)은 여행 일정 관리 PWA 여기로를 제공하면서 처리하는 개인정보를 다음과 같이 안내합니다.

## 2. 처리의 근거

- 계정, 로그인 세션, 여행 저장·동기화·공유: 이용자가 요청한 서비스 제공과 약관 이행
- Google 계정 정보와 정책 동의 기록: 이용자가 로그인 버튼 주변의 고지를 확인하고 계속하기를 선택한 동의
- 보안 이벤트와 요청 제한: 서비스와 이용자를 보호하기 위한 정당한 운영 필요
- 날씨·지도·경로·환율·AI 분석: 이용자가 해당 기능을 요청한 경우에만 필요한 범위에서 처리
- 별도 법령상 보존 의무: `[[운영자 소재지와 사업 형태에 따른 적용 법령 확인 필요]]`

동의를 근거로 처리하는 항목은 동의를 철회할 수 있습니다. Google 로그인 동의를 철회하거나 계정을 삭제하면 계정 기능을 사용할 수 없지만, 내보낸 JSON 파일과 기기에 남긴 오프라인 데이터는 이용자가 직접 관리할 수 있습니다.

## 4. 브라우저·PWA 저장

여기로는 오프라인 사용을 위해 다음 정보를 기기에 저장합니다.

- IndexedDB: 여행 전체 캐시, 동기화 대기열, 기존 여행 접근정보, 파일 원본, 대표사진, 경로 캐시, 백업 상태
- localStorage: 호환용 여행 상태, 개인 준비 체크, 알림 설정·이력, 날씨 캐시, 앱 설치·온보딩 상태, 최대 20개의 정제된 오류 진단 기록
- sessionStorage: 로그인 전 초대 토큰, 당일 알림 중복 방지 값
- Cache Storage: 앱 파일, 공개 법적 문서, 최대 160개의 지도 타일
- HttpOnly 쿠키: 계정 로그인 세션, 10분 OAuth state

예약 PDF·이미지 원본은 기본적으로 해당 기기의 IndexedDB에만 저장합니다. D1에는 파일명·형식·크기·연결 대상 같은 메타데이터만 저장합니다. 대표사진은 공유 표시를 위해 1.5MB 이하의 압축본을 D1에 저장합니다.

계정에서 로그아웃해도 오프라인 여행과 파일 원본은 자동 삭제되지 않습니다. 공용·개인 기기에서는 로그아웃 후 브라우저 데이터도 함께 삭제해야 합니다. 계정 삭제 화면에서 최종 삭제가 성공하면 여기로 앱의 로컬 데이터를 함께 지웁니다.

## 5. 예약 문서 AI 분석

사용자가 예약 문서 분석을 실행한 경우에만 최대 8MB의 PDF/JPG/PNG/WEBP 원본이 Cloudflare Worker와 Workers AI로 전송됩니다. 목적은 문서를 텍스트로 변환하고 항공편·숙소·예약 후보값을 만드는 것입니다.

- 분석 결과는 바로 여행에 저장되지 않으며 이용자가 검토하고 적용할 항목을 선택합니다.
- 여기로는 문서 원본이나 미적용 분석 결과를 D1에 저장하지 않습니다.
- 적용한 예약정보 필드만 일반 여행 데이터로 동기화됩니다.
- AI 결과는 부정확할 수 있으므로 예약 원문과 다시 확인해야 합니다.
- `[[Cloudflare Workers AI의 고객 데이터 처리 위치, 로그 보존, 모델 학습 사용 여부를 운영 계정의 계약·설정에서 확인 필요]]`

## 6. 공유 여행에서 보이는 정보

초대 링크로 여행에 참여한 사람은 역할에 따라 해당 여행의 일정, 항공편, 숙소, 예약번호, 경비, 공용 준비물, 참여자 표시명, 변경 이력을 볼 수 있습니다.

- 소유자: 여행 삭제, 초대·권한·휴지통·긴급 복구 관리
- 편집 가능: 여행 데이터 편집
- 보기 전용: 여행 데이터 열람

파일 원본은 파일을 저장한 기기에만 있으며 다른 참여자에게는 파일명·형식·크기·보관 기기 같은 메타데이터만 보일 수 있습니다. 공유 전에 예약번호, 메모, 장소, 경비 등 동행자에게 보여도 되는 정보인지 확인해야 합니다. 초대 링크를 받은 사람이 다시 전달할 수 있으므로 필요하면 1회용·만료 설정을 사용하고 링크를 취소해야 합니다.

## 9. 안전성 확보 조치

- Google Authorization Code + PKCE, state, nonce 및 1회용 OAuth 거래
- 로그인 쿠키 `Secure`, `HttpOnly`, `SameSite=Lax`
- 서버에는 계정·기존 여행 접근 토큰과 초대·연결·복구 코드의 해시만 저장
- 모든 여행 API에서 현재 계정 또는 기존 세션의 여행 membership·role을 서버에서 다시 확인
- 소유권·권한 변경, 계정 삭제, 여행 삭제의 역할 검사
- 요청 제한 키와 보안 이벤트의 IP 주소 해시 처리
- 허용 파일 형식·크기와 실제 파일 시그니처 검사
- 진단 로그 필드 allowlist로 예약번호·토큰·메모·파일 내용 배제
- HTTPS와 엄격한 리퍼러 정책

인터넷 전송이나 저장 시스템의 절대적 안전을 보장할 수는 없습니다. 초대 링크, 긴급 복구 코드, JSON 백업은 비밀번호처럼 안전하게 보관해야 합니다.

## 10. 이용자의 권리와 행사 방법

이용자는 앱에서 다음 작업을 할 수 있습니다.

- 여행·일정·예약·경비·표시명 수정 및 삭제
- JSON으로 여행 데이터 내보내기
- 참여자 권한 변경, 초대 취소, 여행 나가기
- 기기별 로그아웃 및 다른 기기 전체 로그아웃
- 계정 삭제

계정 삭제는 공유 여행의 예기치 않은 손실을 막기 위해 소유한 여행이 있으면 차단됩니다. 먼저 다른 참여자에게 소유권을 이전하거나 그 여행을 삭제해야 합니다. 계정 삭제 후 다른 참여자와 공유된 여행 데이터는 유지되며 탈퇴자의 표시명은 익명화됩니다.

추가 열람·정정·삭제·처리정지 요청: `[[개인정보 문의 이메일]]` / `[[문의 방법 또는 주소]]`. 운영자는 본인 확인 후 적용 법령이 정한 기간에 처리합니다. `[[대한민국 이용자 민원·분쟁조정 안내와 담당자 정보 확인 필요]]`

## 11. 쿠키와 추적

여기로는 로그인 유지와 OAuth 요청 검증을 위한 자체 쿠키만 사용합니다. 광고, 제3자 행동 추적, 마케팅 프로파일링 쿠키를 코드에 포함하지 않습니다. 브라우저에서 쿠키를 차단하면 Google 로그인과 계정 동기화가 동작하지 않을 수 있지만, 이미 저장된 오프라인 데이터는 열 수 있습니다.

## 12. 아동의 개인정보
