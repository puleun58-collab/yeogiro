# 여기로 개인정보 처리방침

> 정책 버전 1.1 · 공고일 2026-09-08 · 시행일 2026-09-08 · 최종 수정일 2026-09-08

정하건(이하 “운영자”)은 개인 운영 형태로 여행 일정 관리 PWA 여기로를 제공하면서 처리하는 개인정보를 다음과 같이 안내합니다.

여기로는 코드상 비밀번호, 결제수단, 연락처, 광고 식별자, 마케팅 수신정보를 수집하지 않습니다. 분석·광고·마케팅 SDK도 사용하지 않습니다.

## 2. 처리의 근거

- 계정, 로그인 세션, 여행 저장·동기화·공유: 이용자가 요청한 서비스 제공과 약관 이행
- Google 계정 정보와 정책 동의 기록: 로그인 버튼 주변의 고지를 확인하고 계속하기를 선택한 동의
- 보안 이벤트와 요청 제한: 서비스와 이용자를 보호하기 위한 정당한 운영 필요
- 날씨·지도·경로·환율·AI 분석: 이용자가 해당 기능을 요청한 경우에만 필요한 범위에서 처리
- 법령상 별도 보존이 요구되는 경우: 대한민국 「개인정보 보호법」 등 관계 법령에 따른 의무 이행

동의를 근거로 처리하는 항목은 동의를 철회할 수 있습니다. Google 로그인 동의를 철회하거나 계정을 삭제하면 계정 기능을 사용할 수 없습니다. 사용자가 직접 내보낸 JSON 파일과 기기에 남은 오프라인 데이터는 사용자가 직접 관리합니다.

## 3. 보유기간과 삭제

| 데이터 | 보유기간 또는 삭제 기준 |
|---|---|
| 계정·Google 연결·정책 동의 | 계정 삭제 시 삭제 |
| 활성 계정 세션 | 발급 후 30일 또는 먼저 로그아웃·해지할 때까지 |
| 해지된 계정·기존 기기 세션 | 해지 후 최대 30일 |
| OAuth state·nonce·PKCE 거래 | 10분 유효, 만료 후 일일 정리 |
| 여행과 종속 데이터 | 소유자가 여행을 삭제할 때까지. 삭제 시 D1 종속 데이터도 삭제 |
| 공유 여행에서 탈퇴한 계정 | 계정 정보와 연결은 삭제하고 참여자 표시명은 “탈퇴한 사용자”로 익명화. 공유 여행 데이터는 다른 참여자를 위해 유지 |
| 초대 | 설정된 만료, 취소, 1회 사용 완료 또는 여행 삭제까지 |
| 기기 연결 코드 | 15분 또는 1회 사용, 취소, 여행 삭제 중 먼저 오는 때까지 |
| 기존 긴급 복구 코드 해시 | 새 코드는 발급하지 않으며 기존 해시는 여행 삭제까지 레거시 교환을 위해 유지 |
| 보안·인증 이벤트와 IP 해시 | 최대 180일 |
| rate-limit 기록 | 설정된 제한 시간 창 종료 후 정리 |
| 브라우저 데이터 | 사용자가 항목 또는 브라우저/앱 데이터를 지울 때까지. 계정 삭제 성공 후 여기로가 IndexedDB와 `yeogiro-*` 웹 저장소를 삭제 |
| 사용자가 내보낸 JSON 파일 | 운영자 서버에는 저장하지 않으며 사용자가 저장한 위치에서 직접 관리 |

법령에 따라 별도 보관이 필요한 경우에는 해당 정보를 분리하여 필요한 기간만 보관합니다. 현재 서비스에는 결제·전자상거래 기록이 없습니다.

## 4. 브라우저·PWA 저장

- IndexedDB: 여행 전체 캐시, 동기화 대기열, 기존 여행 접근정보, 파일 원본, 대표사진, 경로 캐시, 마지막 수동 내보내기 상태
- localStorage: 호환용 여행 상태, 개인 준비 체크, 알림 설정·이력, 날씨 캐시, 앱 설치·온보딩 상태, 최대 20개의 정제된 오류 기록
- sessionStorage: 로그인 전 초대 토큰, 당일 알림 중복 방지 값
- Cache Storage: 앱 파일, 공개 법적 문서, 최대 160개의 지도 타일
- HttpOnly 쿠키: 계정 로그인 세션, 10분 OAuth state

예약 PDF·이미지 원본은 기본적으로 해당 기기의 IndexedDB에만 저장합니다. D1에는 파일명·형식·크기·연결 대상 같은 메타데이터만 저장합니다. 대표사진은 공유 표시를 위해 1.5MB 이하의 압축본을 D1에 저장합니다.

계정에서 로그아웃해도 오프라인 여행과 파일 원본은 자동 삭제되지 않습니다. 공용·개인 기기에서는 로그아웃 후 브라우저 데이터도 함께 삭제해야 합니다. 계정 삭제가 성공하면 여기로 앱의 로컬 데이터를 함께 지웁니다.

## 5. 예약 문서 AI 분석

사용자가 예약 문서 분석을 실행한 경우에만 최대 8MB의 PDF/JPG/PNG/WEBP 원본이 Cloudflare Worker와 Workers AI로 전송됩니다.

- 분석 결과는 바로 여행에 저장되지 않으며 사용자가 검토하고 적용할 항목을 선택합니다.
- 문서 원본과 미적용 분석 결과는 D1에 저장하지 않습니다.
- 적용한 예약정보 필드만 일반 여행 데이터로 동기화됩니다.
- AI 결과는 부정확할 수 있으므로 예약 원문과 다시 확인해야 합니다.
- 플랫폼 수준의 처리 위치, 로그 보존과 고객 데이터 취급은 Cloudflare 계정 설정과 계약 및 제공자 정책을 따릅니다.

## 6. 공유 여행에서 보이는 정보

초대 링크로 참여한 사람은 역할에 따라 일정, 항공편, 숙소, 예약번호, 경비, 공용 준비물, 참여자 표시명과 변경 이력을 볼 수 있습니다.

- 소유자: 여행 삭제, 초대·권한·휴지통·소유권 관리
- 편집 가능: 여행 데이터 편집
- 보기 전용: 여행 데이터 열람

파일 원본은 저장한 기기에만 있으며 다른 참여자에게는 파일 메타데이터만 보일 수 있습니다. 공유 전에 예약번호, 메모, 장소와 경비를 동행자에게 공개해도 되는지 확인해야 합니다.

## 8. 국외 이전

여기로는 글로벌 인프라와 외부 API를 사용하므로 정보가 대한민국 밖에서 처리될 수 있습니다. 현재 배포 설정은 특정 처리 국가를 고정하지 않습니다.

| 이전받는 자 | 처리 위치와 항목 | 목적·시점·방법 | 보유 기준 |
|---|---|---|---|
| Cloudflare, Inc. 및 계약상 처리 법인 | 제공자의 글로벌 인프라. 네트워크 요청, 계정·여행 데이터, 압축 대표사진, 선택한 AI 분석 문서 | 서비스 또는 분석 사용 시 암호화된 네트워크 전송 | 여기로의 제3조와 Cloudflare 정책·계약 |
| Google 및 계약상 처리 법인 | 제공자의 글로벌 인프라. OAuth 요청과 Google 계정 식별정보 | 로그인 선택 시 암호화된 네트워크 전송 | Google 정책과 여기로 계정 삭제 기준 |
| 외부 데이터 API 운영자 | 각 제공자의 인프라. 도시·장소·좌표·통화·네트워크 정보 | 해당 기능 요청 시 암호화된 네트워크 전송 | 각 제공자 정책 |

국외 처리를 원하지 않으면 Google 로그인, 문서 AI 분석, 날씨·지도·경로·환율 기능을 사용하지 않을 수 있습니다. Google 로그인을 거부하면 계정 동기화와 새 기기 자동 복원을 사용할 수 없지만 기존 기기의 오프라인 데이터는 계속 열 수 있습니다.

## 9. 안전성 확보 조치

- Google Authorization Code + PKCE, state, nonce 및 1회용 OAuth 거래
- 로그인 쿠키 `Secure`, `HttpOnly`, `SameSite=Lax`
- Google access token과 ID token은 로그인 검증 후 저장하지 않음
- 서버에는 계정·기존 여행 접근 토큰과 초대·연결·기존 복구 코드의 해시만 저장
- 모든 여행 API에서 현재 계정 또는 기존 세션의 membership·role 재검증
- 소유권·권한 변경, 계정 삭제, 여행 삭제의 역할 검사
- 요청 제한 키와 보안 이벤트의 IP 주소 해시 처리
- 허용 파일 형식·크기와 실제 파일 시그니처 검사
- 진단 로그 allowlist로 예약번호·토큰·메모·파일 내용 배제
- 수동 JSON 내보내기에서 인증 토큰, 쿠키, OAuth state, PKCE verifier, Client Secret, API key와 복구 원문 배제

인터넷 전송이나 저장 시스템의 절대적 안전을 보장할 수는 없습니다. 초대 링크와 사용자가 직접 내보낸 JSON 파일은 안전하게 보관해야 합니다.

## 10. 이용자의 권리와 행사 방법

사용자는 앱에서 다음 작업을 할 수 있습니다.

- 여행·일정·예약·경비·표시명 수정 및 삭제
- 여행 데이터를 JSON 파일로 수동 내보내기 및 가져오기
- 참여자 권한 변경, 초대 취소, 여행 나가기
