# 여기로 이용약관

> 정책 버전 1.0 · 공고일 2026-09-07 · 시행일 2026-09-07 · 최종 수정일 2026-09-07
>
> 이 문서는 현재 서비스 동작을 반영한 운영 초안이며 법률 자문이 아닙니다. `[[...]]` 항목은 공개 운영 전에 확인·보완해야 합니다.

## 제1조 목적

이 약관은 `[[운영자 실명 또는 법인명]]`(이하 “운영자”)이 제공하는 여행 일정 관리 PWA “여기로”(이하 “서비스”)의 이용 조건, 운영자와 이용자의 권리·의무, 계정·여행·공유 데이터의 관리 기준을 정합니다.

## 제2조 서비스 내용

서비스는 다음 기능을 제공합니다.

1. 여행명, 기간, 도시, 일정, 항공편, 숙소, 예약정보, 경비, 준비 체크리스트 관리
2. Google 로그인을 통한 계정 생성, 계정별 여행 목록과 새 기기 복원
3. 초대 링크를 통한 여행 공동 편집과 역할별 권한 관리
4. 기기별 오프라인 저장과 동기화
5. 예약 PDF·이미지의 기기 저장 및 선택적 AI 분석
6. 대표사진 공유, 날씨, 지도, 이동 경로, 환율, 캘린더·JSON 내보내기
7. 변경 이력, 휴지통, 기기 관리, 긴급 복구

현재 서비스는 무료로 제공되며 결제 기능이 없습니다. 운영자는 향후 유료 기능을 도입하는 경우 가격, 결제 조건, 환불 기준을 적용 전에 별도로 고지합니다.

## 제3조 약관 동의와 계정

1. 이용자가 Google 로그인 버튼 가까이에 표시된 약관과 개인정보 처리방침 링크를 확인하고 “Google로 계속하기”를 선택하면 현재 표시된 버전에 동의한 것으로 봅니다.
2. 서비스는 Google에서 계정 고유 식별자, 표시명, 이메일, 프로필 사진 URL과 이메일 확인 여부를 받아 자체 계정을 만듭니다. Google 비밀번호는 받거나 저장하지 않습니다.
3. 로그인하지 않아도 기존 기기에 저장된 여행을 오프라인으로 열 수 있습니다. 다만 새 기기 복원, 계정별 여행 목록, 계정 세션 관리에는 로그인이 필요합니다.
4. 이용자는 자신의 Google 계정과 기기를 안전하게 관리해야 합니다. 타인의 계정을 사용하거나 로그인 세션, 초대 링크, 긴급 복구 코드를 무단으로 공유해서는 안 됩니다.
5. 운영자는 비정상 로그인, 자동화 공격, 권한 우회가 의심되면 요청 제한, 세션 해지 또는 접근 제한 조치를 할 수 있습니다.

## 제4조 기존 여행의 계정 연결

1. 계정 도입 전에 만든 여행은 기존 기기에서 계속 사용할 수 있습니다.
2. 로그인만으로 기존 여행을 강제로 계정에 귀속하지 않습니다. 이용자가 “여행 연결”을 선택하면 서버가 그 기기의 유효한 기존 여행 접근정보를 다시 확인한 후 membership을 계정에 연결합니다.
3. 이미 다른 계정에 연결된 membership이거나 같은 계정의 membership이 중복되는 경우 연결을 거부합니다.
4. 연결 후 새 기기에서 같은 Google 계정으로 로그인하면 해당 여행을 자동으로 내려받습니다.
5. 기존 연결 코드와 긴급 복구 방식은 이전 이용자를 위해 계속 지원하지만, 일반적인 기기 교체에는 Google 로그인을 우선 사용합니다.

## 제5조 여행 소유권과 공유 권한

1. 새 여행을 서버에 처음 저장한 이용자는 소유자가 됩니다.
2. 소유자는 초대 생성·취소, 참여자 권한 변경, 소유권 이전, 휴지통 비우기, 긴급 복구 코드 발급, 여행 삭제를 할 수 있습니다.
3. 편집 가능 참여자는 여행 내용을 편집할 수 있고, 보기 전용 참여자는 열람만 할 수 있습니다.
4. 초대받은 사람은 여행의 일정, 항공편, 숙소, 예약번호, 경비, 공용 준비물, 참여자 표시명, 변경 이력을 역할에 따라 볼 수 있습니다.
5. 초대 링크를 받은 사람이 링크를 다시 전달할 수 있습니다. 소유자는 필요한 경우 1회용·만료 옵션을 사용하고 사용이 끝난 초대를 취소해야 합니다.
6. 파일 원본은 원칙적으로 저장한 기기에만 있습니다. 다른 참여자는 파일명, 형식, 크기, 연결 대상, 보관 기기 등의 메타데이터를 볼 수 있습니다. 압축 대표사진은 여행 참여자에게 공유됩니다.
7. 이용자는 다른 사람의 이름, 예약정보, 위치, 비용을 입력하거나 공유할 적법한 권한이 있는지 확인해야 합니다.

## 제6조 데이터 저장, 동기화와 오프라인 사용

1. 여행 데이터는 기기의 IndexedDB와 Cloudflare D1 사이에서 동기화됩니다. 네트워크가 없으면 변경을 기기에 보관하고 연결이 회복되면 저장을 시도합니다.
2. 동기화 충돌이 발생하면 이용자는 서버 최신본 또는 이 기기 변경본을 선택할 수 있습니다.
3. 서비스는 인터넷 연결, 브라우저 저장공간, 기기 설정, 외부 서비스 상태에 따라 일부 기능이 지연되거나 제한될 수 있습니다.
4. 앱 삭제, 브라우저 데이터 삭제, 저장공간 정리, 기기 분실은 기기에만 있는 파일 원본을 제거할 수 있습니다. 필요한 자료는 JSON 백업과 원본 파일을 별도로 보관해야 합니다.
5. 운영자는 합리적인 범위에서 서비스를 유지하지만 중단 없는 동작, 모든 기기의 호환, 데이터의 영구 보존을 보장하지 않습니다.

## 제7조 예약 문서와 AI 분석

1. 예약 PDF·이미지 원본은 기본적으로 해당 기기에 저장됩니다. 이용자가 문서 분석을 실행한 경우에만 최대 8MB 원본이 Cloudflare Worker와 Workers AI로 전송됩니다.
2. AI 분석 결과는 후보값이며 바로 저장되지 않습니다. 이용자는 원문과 비교해 날짜, 시간, 공항, 예약번호, 숙소, 금액을 직접 확인한 후 적용해야 합니다.
3. AI는 내용을 누락하거나 잘못 읽을 수 있습니다. 분석 결과만 믿고 탑승, 체크인, 결제, 환불 또는 출입국 결정을 해서는 안 됩니다.
4. 법이 허용하는 범위에서 운영자는 이용자가 검토하지 않은 AI 결과의 오류로 발생한 손해를 책임지지 않습니다. 운영자의 고의 또는 중대한 과실 등 책임을 제한할 수 없는 경우는 제외합니다.

## 제8조 날씨, 지도, 경로와 환율

1. 날씨, 지도 타일, 지오코딩, 경로와 환율은 외부 공개 API의 데이터를 사용합니다.
2. 예보, 좌표, 경로, 소요시간, 환율은 지연되거나 부정확할 수 있으며 실제 교통, 기상, 금융 거래 조건을 보장하지 않습니다.
3. 환율은 여행 경비 정리를 위한 참고값입니다. 금융 거래, 회계, 세무 또는 투자 판단의 기준으로 사용해서는 안 됩니다.
4. 출발 전 항공사·숙소·교통기관·기상기관·금융기관의 공식 정보를 확인해야 합니다.
5. Google Maps 등 외부 페이지를 열면 해당 제공자의 약관과 개인정보 정책이 적용됩니다.

## 제9조 JSON 백업과 복원

1. JSON 백업에는 여행 일정, 항공편, 숙소, 경비, 공용 준비물과 현재 기기에서 읽을 수 있는 일부 파일 원본이 포함될 수 있습니다.
2. 백업에는 Google 계정 식별자·이메일, 로그인 쿠키·토큰, 기존 여행 접근 토큰, 초대 토큰, 긴급 복구 코드, 서버 보안 이벤트가 포함되지 않습니다.
3. 이용자는 백업 파일에 예약번호, 위치, 비용, 파일 원본 등 민감한 여행정보가 포함될 수 있음을 알고 안전하게 보관해야 합니다.
4. 기존 여행에 복원해도 현재 membership과 역할은 바뀌지 않습니다. 보기 전용 이용자는 서버 데이터를 덮어쓸 수 없습니다.
5. “새 여행으로 복원”하면 여행과 하위 ID를 새로 만들며, 서버에 처음 저장한 현재 계정 또는 기기가 소유자가 됩니다.
6. 이용자가 앱 밖으로 다운로드하거나 제3자에게 전달한 백업 사본은 운영자가 직접 삭제할 수 없습니다.

## 제10조 로그아웃, 여행 나가기, 여행 삭제와 계정 삭제

각 작업의 효과는 다릅니다.

- 로그아웃: 선택한 계정 로그인 세션만 종료합니다. 기기의 오프라인 여행과 파일은 남습니다.
- 다른 기기 로그아웃: 선택한 기기의 로그인만 종료하고 여행과 다른 기기는 유지합니다.
- 여행 공유에서 나가기: 내 참여 권한과 해당 여행의 기존 세션을 해지합니다. 공유 여행 자체는 유지됩니다.
- 여행 삭제: 소유자만 할 수 있으며 서버의 해당 여행과 종속 데이터를 삭제합니다. 모든 참여자가 더 이상 접근할 수 없습니다.
- 계정 삭제: Google 연결, 계정 개인정보, 로그인 세션과 비소유 여행의 내 참여 권한을 삭제합니다. 공유 여행은 유지하며 표시명은 “탈퇴한 사용자”로 익명화합니다. 소유한 여행이 있으면 예기치 않은 공동 데이터 손실을 막기 위해 삭제할 수 없습니다. 먼저 소유권을 이전하거나 여행을 삭제해야 합니다.

계정 삭제 성공 후 서비스는 현재 기기의 여기로 IndexedDB와 `yeogiro-*` 웹 저장소를 삭제합니다. 사용자가 다운로드한 JSON, 다른 참여자나 기기에 남은 사본, 법령 또는 외부 제공자 정책에 따라 보존되는 기록은 별도입니다.

## 제11조 이용자의 의무와 금지행위

이용자는 다음 행위를 해서는 안 됩니다.

1. 타인의 계정, 세션, 초대, 복구 코드를 무단 사용하거나 권한을 우회하는 행위
2. 다른 사람의 개인정보나 기밀정보를 권한 없이 입력·공유·분석하는 행위
3. 악성 파일, 불법 콘텐츠, 타인의 권리를 침해하는 콘텐츠를 저장하거나 전송하는 행위
4. 서비스 또는 외부 API에 과도한 자동 요청을 보내거나 요청 제한을 우회하는 행위
5. 서비스의 보안, 가용성, 데이터 무결성을 해치는 행위
6. 법령, 공공질서, 제3자의 지식재산권·개인정보·기타 권리를 침해하는 행위

운영자는 위반이 확인되거나 합리적으로 의심되는 경우 관련 세션·초대·접근을 제한하거나 삭제할 수 있습니다. 긴급하지 않은 경우 가능한 범위에서 사유와 이의제기 방법을 안내합니다.

## 제12조 이용자 콘텐츠와 지식재산권

1. 이용자가 입력하거나 업로드한 여행 정보와 파일에 대한 권리는 이용자 또는 정당한 권리자에게 있습니다.
2. 이용자는 서비스 제공, 동기화, 공동 편집, 백업 복원, 이용자가 선택한 AI 분석에 필요한 범위에서 운영자가 해당 콘텐츠를 처리하도록 허용합니다.
3. 서비스의 코드, 브랜드, 디자인, 문서 등 운영자가 권리를 갖는 부분은 관련 법령에 따라 보호됩니다.
4. 외부 지도·날씨·환율 데이터에는 각 제공자의 라이선스와 이용조건이 적용됩니다.

## 제13조 서비스 변경과 중단

1. 운영자는 보안, 법령, 외부 API, 기술 환경 변화에 따라 기능을 수정하거나 중단할 수 있습니다.
2. 계정, 데이터 보존, 공유 권한 등 이용자에게 중요한 변경은 가능한 범위에서 앱이나 공개 페이지로 사전 고지합니다.
3. 긴급 보안 대응, 천재지변, 외부 인프라 장애 등 사전 고지가 어려운 경우에는 사후에 알릴 수 있습니다.
4. 서비스 종료 시 `[[최소 사전 고지 기간]]` 전에 알리고 합리적인 기간 동안 JSON 내보내기 기회를 제공합니다. `[[적용 법령상 요구 기간 확인 필요]]`

## 제14조 책임의 범위

1. 서비스는 여행 정리를 돕는 도구이며 여행상품 판매, 예약 대행, 운송, 숙박, 보험, 금융 또는 전문 자문 서비스가 아닙니다.
2. 운영자는 이용자가 입력한 정보, 다른 참여자가 변경한 내용, 외부 API 또는 AI가 제공한 정보의 정확성을 보장하지 않습니다.
3. 이용자는 중요 예약·결제·출입국·안전 정보를 공식 제공처에서 확인하고 필요한 백업을 유지해야 합니다.
4. 법이 허용하는 범위에서 무료 서비스의 일시적 장애, 외부 제공자의 중단, 이용자의 기기·브라우저 데이터 삭제, 이용자가 공유한 링크·백업 관리 부주의로 인한 손해에 대해 운영자는 책임을 제한할 수 있습니다.
5. 운영자의 고의·중대한 과실, 법령상 제한할 수 없는 소비자 권리와 손해배상 책임은 이 조항으로 제한되지 않습니다.

## 제15조 개인정보

개인정보 처리에는 별도의 [여기로 개인정보 처리방침](/privacy)이 적용됩니다. 개인정보 처리방침은 실제 수집 항목, 기기 저장, 외부 제공자, 보유기간, 계정 삭제 효과를 설명합니다.

## 제16조 약관 변경

1. 약관 변경 시 버전, 공고일, 시행일을 공개 페이지에 표시합니다.
2. 이용자 권리를 중대하게 제한하거나 새로운 개인정보 처리를 요구하는 변경은 `[[적용 법령에 따른 고지 기간과 방법]]`에 따라 알리고 필요한 경우 다시 동의를 받습니다.
3. 시행일 이후 서비스를 계속 이용하면 법이 허용하는 범위에서 변경 약관에 동의한 것으로 볼 수 있습니다. 별도 동의가 필요한 변경에는 이 규칙을 적용하지 않습니다.
