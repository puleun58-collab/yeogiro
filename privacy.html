2. 처리의 근거

  • 계정, 로그인 세션, 여행 저장·동기화·공유: 사용자가 요청한 서비스 제공과 약관 이행
  • Google 계정 정보와 정책 동의 기록: 로그인 버튼 주변 고지를 확인하고 계속하기를 선택한 동의
  • 보안 이벤트와 요청 제한: 서비스와 사용자를 보호하기 위한 정당한 운영 필요
  • 날씨·지도·경로·환율·AI 분석: 사용자가 해당 기능을 요청한 경우에만 필요한 범위에서 처리
  • 법령상 별도 보존이 요구되는 경우: 대한민국 「개인정보 보호법」 등 관계 법령에 따른 의무 이행

동의를 철회하거나 계정을 삭제하면 계정 기능을 사용할 수 없습니다. 사용자가 직접 내보낸 JSON 파일과 기기에 남은 오프라인 데이터는 사용자가 직접 관리합니다.

4. 브라우저·PWA 저장

  • IndexedDB: 여행 캐시, 동기화 대기열, 기존 여행 접근정보, 파일 원본, 대표사진, 경로 캐시, 마지막 수동 내보내기 상태
  • localStorage: 호환용 여행 상태, 개인 준비 체크, 알림 설정·이력, 날씨 캐시, 설치·온보딩 상태, 정제된 오류 기록
  • sessionStorage: 로그인 전 초대 토큰, 당일 알림 중복 방지 값
  • Cache Storage: 앱 파일, 공개 법적 문서, 최대 160개 지도 타일
  • HttpOnly 쿠키: 계정 로그인 세션과 10분 OAuth state

예약 PDF·이미지 원본은 기본적으로 해당 기기에만 저장하고 D1에는 메타데이터만 저장합니다. 대표사진은 공유를 위해 1.5MB 이하 압축본을 D1에 저장합니다. 로그아웃해도 오프라인 데이터는 남으며 계정 삭제가 성공하면 여기로 앱의 로컬 데이터를 함께 지웁니다.

5. 예약 문서 AI 분석

사용자가 분석을 실행한 경우에만 문서 원본이 Cloudflare Worker와 Workers AI로 전송됩니다. 해당 문서는 Cloudflare의 글로벌 인프라를 통해 처리될 수 있습니다. 실제 처리 지역은 Cloudflare의 인프라와 운영 정책에 따라 달라질 수 있습니다.

결과는 바로 저장되지 않으며 사용자가 검토·적용한 필드만 일반 여행 데이터로 동기화됩니다. 문서 원본과 미적용 결과는 D1에 저장하지 않습니다. AI 결과는 예약 원문과 다시 확인해야 합니다.

8. 국외 이전

여기로는 Google 로그인, Cloudflare Workers·D1·Workers AI 등 국외 사업자가 제공하는 서비스를 사용합니다. 해당 기능 이용 시 서비스 제공에 필요한 개인정보가 암호화된 네트워크를 통해 국외에서 처리될 수 있으며, 실제 처리 지역은 각 서비스의 글로벌 인프라 및 운영 정책에 따라 달라질 수 있습니다. 현재 배포 설정은 특정 처리 국가를 고정하지 않습니다.

국외 처리를 원하지 않으면 Google 로그인, 문서 AI 분석, 날씨·지도·경로·환율 기능을 사용하지 않을 수 있습니다. Google 로그인을 거부하면 계정 동기화와 새 기기 자동 복원을 사용할 수 없지만 기존 기기의 오프라인 데이터는 계속 열 수 있습니다.

9. 안전성 확보 조치

  • Google Authorization Code + PKCE, state, nonce, 1회용 OAuth 거래
  • Secure, HttpOnly, SameSite=Lax 로그인 쿠키
  • Google access token과 ID token은 검증 후 저장하지 않음
  • 계정·기존 접근 토큰과 초대·연결·기존 복구 코드의 해시만 서버 저장
  • 모든 여행 API에서 membership과 role 재검증
  • 요청 제한·보안 이벤트의 IP 해시 처리
  • 파일 형식·크기·실제 시그니처 검사
  • 진단 로그 allowlist로 토큰·예약번호·메모·파일 내용 배제
  • 수동 JSON 내보내기에서 인증 토큰, 쿠키, OAuth state, PKCE verifier, Client Secret, API key와 복구 원문 배제

절대적 안전을 보장할 수는 없습니다. 초대 링크와 사용자가 직접 내보낸 JSON 파일은 안전하게 보관하세요.

11. 쿠키와 추적
