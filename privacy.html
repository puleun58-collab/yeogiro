2. 처리의 근거

  • 계정, 로그인 세션, 여행 저장·동기화·공유: 이용자가 요청한 서비스 제공과 약관 이행
  • Google 계정 정보와 정책 동의 기록: 로그인 버튼 주변 고지를 확인하고 계속하기를 선택한 동의
  • 보안 이벤트와 요청 제한: 서비스와 이용자를 보호하기 위한 정당한 운영 필요
  • 날씨·지도·경로·환율·AI 분석: 이용자가 해당 기능을 요청한 경우에만 필요한 범위에서 처리
  • 별도 법령상 보존 의무: [[운영자 소재지와 사업 형태에 따른 적용 법령 확인 필요]]

동의를 철회하거나 계정을 삭제하면 계정 기능을 사용할 수 없습니다. 내보낸 JSON 파일과 기기에 남긴 오프라인 데이터는 이용자가 직접 관리합니다.

4. 브라우저·PWA 저장

  • IndexedDB: 여행 캐시, 동기화 대기열, 기존 여행 접근정보, 파일 원본, 대표사진, 경로 캐시, 백업 상태
  • localStorage: 호환용 여행 상태, 개인 준비 체크, 알림 설정·이력, 날씨 캐시, 앱 설치·온보딩 상태, 최대 20개의 정제된 오류 기록
  • sessionStorage: 로그인 전 초대 토큰, 당일 알림 중복 방지 값
  • Cache Storage: 앱 파일, 공개 법적 문서, 최대 160개 지도 타일
  • HttpOnly 쿠키: 계정 로그인 세션과 10분 OAuth state

예약 PDF·이미지 원본은 기본적으로 해당 기기에만 저장하고 D1에는 메타데이터만 저장합니다. 대표사진은 공유를 위해 1.5MB 이하 압축본을 D1에 저장합니다. 로그아웃해도 오프라인 데이터는 남으므로 공용 기기에서는 브라우저 데이터도 지워야 합니다.

5. 예약 문서 AI 분석

이용자가 분석을 실행한 경우에만 문서 원본이 Cloudflare Worker와 Workers AI로 전송됩니다. 결과는 바로 저장되지 않으며 이용자가 검토·적용한 필드만 일반 여행 데이터로 동기화됩니다. 문서 원본과 미적용 결과는 D1에 저장하지 않습니다.

AI 결과는 부정확할 수 있으므로 예약 원문과 다시 확인해야 합니다. [[Cloudflare Workers AI의 고객 데이터 처리 위치, 로그 보존, 모델 학습 사용 여부를 운영 계약·설정에서 확인 필요]]

6. 공유 여행에서 보이는 정보

초대받은 사람은 역할에 따라 일정, 항공편, 숙소, 예약번호, 경비, 공용 준비물, 참여자 표시명과 변경 이력을 볼 수 있습니다. 소유자는 권한·초대·휴지통·복구·여행 삭제를, 편집 가능 참여자는 내용 편집을, 보기 전용 참여자는 열람을 할 수 있습니다.

파일 원본은 저장한 기기에만 있고 다른 참여자에게는 메타데이터만 보일 수 있습니다. 공유 전에 예약번호, 메모, 장소와 비용을 동행자에게 공개해도 되는지 확인하세요.

9. 안전성 확보 조치

  • Google Authorization Code + PKCE, state, nonce, 1회용 OAuth 거래
  • Secure, HttpOnly, SameSite=Lax 로그인 쿠키
  • 계정·기존 접근 토큰과 초대·연결·복구 코드의 해시만 서버 저장
  • 모든 여행 API에서 membership과 role 재검증
  • 요청 제한·보안 이벤트의 IP 해시 처리
  • 파일 형식·크기·실제 시그니처 검사
  • 진단 로그 allowlist로 토큰·예약번호·메모·파일 내용 배제

절대적 안전을 보장할 수는 없습니다. 초대 링크, 긴급 복구 코드, JSON 백업은 비밀번호처럼 보관하세요.

10. 이용자의 권리와 행사 방법

앱에서 여행·표시명 수정·삭제, JSON 내보내기, 권한 변경, 초대 취소, 여행 나가기, 기기별 로그아웃, 계정 삭제를 할 수 있습니다.

계정 삭제는 소유한 여행이 있으면 차단됩니다. 먼저 소유권을 이전하거나 여행을 삭제해야 합니다. 비소유 공유 여행은 유지하며 탈퇴자의 표시명을 익명화합니다.

11. 쿠키와 추적

로그인 유지와 OAuth 검증을 위한 자체 쿠키만 사용합니다. 광고, 제3자 행동 추적, 마케팅 프로파일링 쿠키를 코드에 포함하지 않습니다. 쿠키를 차단하면 계정 동기화는 동작하지 않을 수 있지만 이미 저장된 오프라인 데이터는 열 수 있습니다.
