# 여기로

**배포 주소:** https://yeogiro.puleun58.workers.dev

여러 여행의 일정, 항공편, 예약 서류와 이동 경로를 관리하는 모바일 우선 여행 플래너입니다.

## 주요 기능

- 여행·일정·항공편·숙소 정보를 Cloudflare D1에 동기화
- 소유자·편집자·보기 전용 권한과 1회용·다회용·`계속 사용` 초대 링크를 지원하는 여행 공유
- Google 계정 로그인, 계정별 여행 목록, 새 기기 자동 복원과 기기별 계정 세션 관리
- IndexedDB 오프라인 캐시와 네트워크 복구 후 변경사항 동기화
- PDF·이미지 예약 문서 AI 자동 입력과 기기 내 예약 서류 보관
- 오늘 일정 요약, 이동 예상시간·충돌 경고, 이동수단별 지도 경로
- 알람, 안정화된 ICS 캘린더, 고급 데이터 관리의 수동 JSON 내보내기·가져오기, 설치형 PWA
- 오프라인 앱 셸과 최근 지도 타일 캐시
- 설정 `앱 상태 진단`에서 앱 버전·동기화·Service Worker·IndexedDB·API 상태와 최근 오류 코드 확인

## PWA

홈 화면 추가 방법을 하나의 중앙 모달에서 모두 확인할 수 있습니다. 설정 → `앱 안내` → `홈 화면에 추가`로 언제든 다시 열 수 있습니다.

- 앱 아이콘과 제목 아래 연한 neutral 영역에 실제 로고가 표시된 `Chrome`과 `Safari` 섹션을 divider로 구분해 나란히 보여줍니다.
- 각 브라우저는 핵심 2단계만 표시합니다. Chrome은 `더보기 메뉴` → `홈 화면에 추가`, Safari는 `공유` → `홈 화면에 추가`이며 단계마다 시스템 아이콘을 함께 보여줍니다.
- 카카오톡 등 인앱 브라우저에서는 추가가 불가능함을 먼저 알리고 `Safari로 열기`를 안내합니다.
- 모달에는 큰 설치 버튼을 두지 않습니다. `beforeinstallprompt`를 사용할 수 있는 Android 환경에서는 설정의 `홈 화면에 추가`와 상단 `앱 설치` 버튼이 시스템 설치창을 바로 실행하고, iOS에서는 설치 prompt를 만들지 않습니다.
- 이미 홈 화면 앱(standalone)으로 실행 중이면 자동·수동 모두 설치 안내를 표시하지 않고 설정에서도 설치 항목을 숨깁니다.

자동 노출은 여행을 하나 이상 만든 뒤 두 번째 방문부터이며, 첫 실행 온보딩 중에는 노출하지 않습니다. `×`로 닫으면 21일 동안 다시 노출하지 않고, `다시 보지 않기`를 선택하면 해당 기기에서 더 이상 노출하지 않습니다. 두 설정은 `localStorage`의 `yeogiro-install-guide`에만 저장하며 여행 데이터나 D1에는 저장하지 않습니다. 설치 안내와 `앱 업데이트` 안내는 서로 다른 화면과 상태로 관리합니다.
미로그인 첫 진입에서는 전용 시작 화면에서 `Google로 계속하기` 또는 `로그인 없이 시작`을 선택합니다. 로그인 상태 확인이 끝나기 전에는 앱이나 로그인 화면을 전환해 보이지 않습니다. 로컬 시작을 선택한 기기는 이후 기존 오프라인 흐름으로 바로 진입하며, `내 정보`에서 같은 Google 로그인 버튼을 사용할 수 있습니다.


최근 여행 데이터는 IndexedDB에 캐시되어 오프라인에서도 열 수 있고, 오프라인 변경사항은 연결이 복구되면 D1과 동기화됩니다. 지도, 경로 검색과 예약 문서 AI 분석은 네트워크 연결이 필요합니다.

여행 저장은 revision 갱신과 하위 데이터를 하나의 D1 배치로 처리합니다. 다른 기기와 수정이 겹치면 서버 최신 내용 또는 이 기기의 변경사항 중 유지할 내용을 직접 선택하며, 선택 전에는 어느 쪽도 자동으로 덮어쓰지 않습니다. 상단 상태 표시를 누르면 마지막 동기화 시각과 대기 건수, 오프라인 보관 상태를 확인할 수 있습니다.

Google 로그인 계정은 `accounts`와 `auth_sessions`로 관리합니다. 같은 Google 계정으로 로그인하면 계정에 연결된 여행을 새 기기에서 자동으로 불러옵니다. 로그인 전 로컬 여행은 자동 귀속하지 않고 사용자가 `여행 연결`을 선택할 때만 기존 여행 세션을 검증해 계정에 연결합니다. 신규 긴급 복구 코드는 발급하지 않으며, 이미 발급된 코드의 SHA-256 해시와 교환 API만 레거시 호환을 위해 유지합니다.

PDF와 예약서류 이미지는 비용이 발생할 수 있는 공용 객체 저장소를 사용하지 않고 각 기기의 IndexedDB에만 저장합니다. 공유 여행에서는 파일명과 연결 정보가 보이지만 원본 파일은 저장한 기기에서만 열 수 있습니다. 여행 대표사진은 모바일에서 압축한 한 장만 권한이 보호된 D1 저장소로 동기화되어 동행자도 같은 배경을 볼 수 있습니다. 기존 `localStorage` 데이터는 최초 실행 시 D1·IndexedDB 구조로 자동 이전하며 안전을 위해 원본을 즉시 삭제하지 않습니다.

## 앱 상태 진단과 오류 기록

설정 → `앱 안내` → `앱 상태 진단`에서 지원에 필요한 상태만 확인할 수 있습니다. 홈 화면에는 노출하지 않습니다.

- 앱 버전은 `package.json` 버전과 배포 커밋으로 만들어 `npm run build`가 `index.html`에 주입합니다. 예: `v1.0.0 · 1056eaa`
- 동기화는 앱이 실제로 사용하는 상태값(마지막 저장 시각, 마지막 실패 시각·코드, 대기 건수, 충돌 여부)을 그대로 보여줍니다.
- Service Worker 상태와 현재 앱 셸 캐시 이름을 표시하며 강제 새로고침 버튼은 제공하지 않습니다.
- 기기 저장소는 IndexedDB 이름·버전, 저장 대기 건수, 연결된 여행 수만 표시합니다.
- API·D1 상태는 `GET /api/health`가 `SELECT 1`로 D1 연결만 확인합니다. 사용자 데이터를 읽지 않습니다.
- 오류 기록은 발생 시각, 오류 코드, 분류(network·sync·conflict·storage·api·weather·route·document-analysis·permission·pwa·unknown), 화면, 앱 버전만 남깁니다. 예약번호·토큰·복구키·메모·문서 내용·파일 원본은 저장하지 않습니다.
- 같은 오류가 1분 안에 반복되면 한 항목으로 합산해 `WEATHER_FETCH × 12` 형태로 표시하고 최대 20건만 보관합니다.
- `진단 정보 복사`는 위 상태 요약과 오류 코드만 복사합니다.

## 기술 구성

- 순수 HTML, CSS, JavaScript
- Cloudflare Workers, D1, Workers AI, Static Assets
- IndexedDB 오프라인 캐시·파일 저장
- Wrangler

## 서체

앱에는 LY Corp.의 `LINE Seed KR` Regular·Bold 웹폰트를 자체 포함합니다. 폰트는 SIL Open Font License 1.1로 제공되며 라이선스 전문은 `assets/fonts/OFL-LINE-Seed.txt`에 있습니다.

## 로컬 실행

```bash
npm install
npx wrangler d1 migrations apply yeogiro-db --local
npx wrangler dev --local
```

핵심 권한·초대·충돌·문서 검증 API 통합 테스트는 로컬 D1과 Worker를 사용합니다.

```bash
npm test
```

배포 후 운영 Worker의 여행 생성, 1회용 초대, revision 충돌과 정리까지 확인하려면 다음 명령을 실행합니다. 검증용 여행은 테스트 종료 시 삭제합니다.

```bash
npm run test:production-smoke
```

## 운영 검증 범위

`npm test`는 다음 시나리오를 로컬 D1과 실제 Worker 런타임에서 검증합니다.

- owner / editor / viewer 권한과 관리 API 차단
- 1회용·다회용 초대, 만료, 사용 횟수와 취소
- 표시명 변경과 참여자 목록 반영
- 참여자 권한 변경·제거와 마지막 소유자 보호
- 신규 긴급 복구 코드 발급 중단, 기존 복구 코드 오입력 거부와 레거시 교환
- 기기별 세션 발급·이름 변경·연결 해제와 해제 토큰 401
- 소유권 이전 후 기존 소유자의 편집 가능 전환
- optimistic revision 409와 두 충돌 선택 문구
- 일정·항공편·숙소·예약 서류, 휴지통, IndexedDB, PWA 캐시, JSON 백업·복원

## 현재 제한사항

- 새 기기 자동 복원에는 같은 Google 계정 로그인이 필요합니다. 계정 도입 전에 발급된 복구·연결 코드는 레거시 경로에서만 사용할 수 있습니다.
- 플랫폼과 앱/브라우저 유형만 표시하며 정확한 휴대폰 모델은 추측하지 않습니다.
- 예약 서류 원본은 기기별 IndexedDB에 저장되어 다른 기기에는 자동 복제되지 않습니다.
- 브라우저 자동화만으로 iOS 홈 화면 설치와 운영체제 공유창 전체를 재현할 수 없어 실제 iPhone PWA에서 릴리스 전 수동 확인이 필요합니다.

## 배포

```bash
npm install
npx wrangler d1 migrations apply yeogiro-db --remote
npm run deploy
```

`npm run deploy`는 구문 검사, 단위·통합 테스트, 실제 브라우저 기반 2기기 E2E, 프로덕션 빌드를 모두 통과한 경우에만 배포합니다. 최초 E2E 실행 전에는 `npx playwright install chromium`으로 브라우저를 설치하세요. 실기기 검증 항목은 [Release Checklist](docs/RELEASE_CHECKLIST.md)에 정리되어 있습니다.

배포 설정에는 D1 `DB`, Workers AI `AI`, Static Assets `ASSETS` 바인딩이 필요합니다. R2는 활성화하지 않으며 PDF와 예약서류 이미지는 각 기기의 IndexedDB에 저장합니다. 공유용 여행 대표사진만 1.5MB 이하로 압축해 D1에 저장합니다.
